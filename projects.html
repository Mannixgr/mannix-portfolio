CloudGuard: Agentic AWS Operations Assistant

Catch the bill before it catches you.

An AWS operations tool I'm building in phases: read-only scans under a least-privilege IAM role, then detection rules for cost waste and security misconfigurations, then an AI agent that investigates what it finds. Each detection rule is tested against resources I misconfigure on purpose in a separate sandbox account.

  • BuiltA read-only scanner role in Terraform: AWS security-audit and view-only policies, MFA required to assume it, and an explicit deny on reading Terraform state.
  • In progressFirst read-only boto3 scans: EC2, NAT gateways, VPN and Elastic IPs, flagging missing tags.
  • NextDetection rules, tested against seeded misconfigurations.
  • PlannedAn agentic investigator: an LLM agent calls read-only AWS tools (CloudTrail, CloudWatch, the scans), explains the likely cause and proposes a fix as a Terraform change that waits for human approval.

Python · boto3 · LLM agents (tool calling) · Terraform · FastAPI

UniWallet: Student Budget Forecaster

Know where you stand before payday.

A hackathon app built with Shayan Baig for students living paycheque to paycheque. You enter your balance, pay date and bills. It ranks what to pay first, projects what you'll have left before payday, and an AI coach answers questions using your actual numbers. I built the backend; Shayan built the frontend.

  • BuiltAn Express and TypeScript REST API on PostgreSQL through Prisma, with zod request validation and a dashboard endpoint that returns a whole page's data in one call.
  • BuiltA rule-based forecast does all the money math. GPT-4o-mini gets the precomputed numbers and only explains them, so the coach can't make figures up. The coach endpoint is rate-limited.
  • BuiltAfter the hackathon: connected the Next.js frontend to the API, added a phone layout, and a rule-based fallback when the AI endpoint is unavailable.

TypeScript · Express · Prisma · PostgreSQL · OpenAI API · zod · Next.js
