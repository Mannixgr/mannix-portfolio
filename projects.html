Enterprise Hybrid AWS Environment

Rebuilt from code. Zero long-lived keys.

A multi-AZ AWS environment that rebuilds from code instead of console clicks — a production-structured Terraform codebase (bootstrap, modules, environments) for the VPC, EC2 and IAM. A multi-region CloudTrail trail logs every API call to S3 with log-file validation, and a CloudWatch billing alarm guards spend. GitHub Actions deploys it with short-lived OIDC credentials, so there are no long-lived AWS keys to leak. In progress: bringing the billing alarm and its email alerts under Terraform. Next: a site-to-site VPN linking it to my homelab.

Network & Virtualization Homelab

Self-hosted, with zero ports opened.

A Proxmox host running containers and a Docker VM behind a Cisco RV260 and Catalyst 3550 — including the server that hosts this site. Remote admin goes through a Tailscale subnet route and public traffic through Tailscale Funnel, so no ports are opened on the router. In progress: splitting the flat LAN into server, client and management VLANs with ACLs between them.

Portfolio Site

Every push ships. Nothing else gets in.

Self-hosted in my homelab and deployed on every push. A GitHub Actions workflow joins my tailnet as an ephemeral CI node that can reach exactly one host on port 22, then rsyncs the site to a Caddy container. The deploy user has no shell — its key can only run rsync into the web root, enforced by a wrapper script. Getting there took four fixes, written up below.
